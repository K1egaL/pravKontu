Честный рандомайзер для выбора ученика на уроке.

## Что это

Программа выбирает число от 1 до 36. Диапазон можно менять. Каждый выбор
делается через модуль secrets, то есть криптографически стойким способом.
Никаких заранее заготовленных чисел и подкруток.

## Почему этому можно доверять

Три причины:

- Исходный код открыт на GitHub, любой может его прочитать.
- Каждый выбор записывается в лог-файл с датой и временем.
- В основе лежит модуль secrets, а не random.

## Быстрый старт

Скачайте pravKontu.exe из раздела Releases и запустите. Установка не нужна.

## Установка из исходников

Нужен Python 3.10 или новее, и PySide6 как установленный packages

pip install -r requirements.txt
python main.py

## Сборка exe

pip install pyinstaller
pyinstaller --onefile --windowed --name pravKontu main.py
text


Готовый файл появится в папке dist.

## Как пользоваться

- Выберите диапазон в полях "от" и "по", нажмите "Применить".
- Нажмите "Выбрать" или клавишу Enter.
- Число мелькает 5 секунд, затем показывается результат.
- Справа ведётся история выпадений текущей сессии.
- Кнопка "Сбросить историю" очищает историю и заново наполняет мешок.

## Логика без повторов

Пока не выпадут все числа из диапазона, ни одно число не повторится.
Когда мешок опустеет, он автоматически наполняется заново, и в лог
пишется запись об этом.

## Журнал

Файл pravKontu_log.txt создаётся рядом с программой. В нём видно каждый
выбор: дата, время, число, сколько осталось в мешке.

## Частые вопросы

Можно ли запустить без установки Python?
Да, скачайте готовый exe из раздела Releases.

Куда сохраняется журнал?
Рядом с exe или рядом с main.py, если запускаете из исходников.

Что делать, если учеников меньше 36?
Поменяйте диапазон в полях "от" и "по".

Почему нет повторов?
Так задумано. Никто не выпадет дважды, пока не выпадут все.
